Política de Privacidade

Última atualização: 14 de outubro de 2026.

Esta política vale para o app "Musicas GauchIAs Bot", usado por Jéfferson Tales para publicar vídeos nos próprios canais do YouTube (Músicas GaúchIAs e BassVIA).

Quem usa

Só o autor, com as contas dos próprios canais. O app não é oferecido a outras pessoas.

Dados acessados

Com a permissão do Google (escopos do YouTube), o app envia vídeos, miniaturas, títulos, descrições e tags para o canal autorizado e consulta qual canal está conectado. Ele não lê nem coleta dados de inscritos, espectadores ou de outras contas.

Armazenamento

O token de acesso fica só no computador do autor. Nenhum dado é vendido, compartilhado ou enviado a terceiros além da própria API do YouTube.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso dos dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.
